# Misc
Randoms stuff mostly in PowerShell.

| Script | What it does |
| --- | --- |
| `ExchangeConnector.ps1` | Connect to Exchange Online with MFA, using the modern `ExchangeOnlineManagement` module (auto-installs it if missing) |
| `getlocaladmins.ps1` | `Get-LocalAdmins`: lists members of the local Administrators group on remote PCs (CIM-based, works in PS 5.1 and 7) |
| `Search-RedditPatchTuesday.ps1` | `Search-RedditPatchTuesday`: finds the /r/sysadmin Patch Tuesday megathread and pulls every KB number from its comments |
| `Numlock ON at Windows login screen.ps1` | Sets NumLock ON at the Windows login screen (needs an elevated shell) |
| `logkill.bat` | Clears every Windows event log (must run elevated) |
| `PromptP$` | Archive: my old PowerShell 5.1 work profile (sanitized: internal hostnames/IPs removed) |
| `April/incredible1ofapril` | The classic PowerShell April Fools ASCII animation with music, kept for posterity (run in Windows PowerShell, needs audio) |
